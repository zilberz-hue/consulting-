# סוויטת ייעוץ עסקי

תוכנה בעברית (RTL) למשרד ייעוץ עסקי, בלי build ובלי שרת. הנתונים נשמרים ב-`localStorage` של הדפדפן.

**להרצה:** פותחים את `standalone.html` בדפדפן (קובץ אחד עצמאי, כולל הלוגו).

## מודולים
1. **ניהול משרד** – לקוחות, פרויקטים, משימות, רישום שעות וחשבוניות.
2. **אבחון עסקי** – שאלון של 20 שאלות ב-5 תחומים, SWOT, דוח והמלצות אוטומטיות.
3. **תוכנית ותחזית** – תחזית תזרים ל-1–36 חודשים, נקודת איזון, גרף וייצוא CSV.
4. **שוק ייעוץ** – בקשות ייעוץ והצעות מחיר; אישור הצעה פותח פרויקט. (הדגמה מקומית.)

## קבצים
| קובץ | תפקיד |
|---|---|
| `index.html`, `app.js`, `styles.css` | קוד המקור |
| `logo.png` | הלוגו (TizonHealth) |
| `build.py` | מרכיב את `standalone.html` ו-`artifact.html`: `python3 build.py` |
| `standalone.html` | הגרסה העצמאית |

## מגבלות
- אין משתמשים או התחברות, והשוק הוא הדגמה בדפדפן אחד. שוק אמיתי דורש backend (Firebase / Netlify Functions).
- החשבונית היא מסמך הדגמה ולא חשבונית מס רשמית.

## פריסה
גוררים את `standalone.html` (בשם `index.html`) ל-app.netlify.com/drop, או מריצים `netlify deploy --prod --dir=.`
